# Final-Year Capstone Project: Warehouse Management System

## About the Project
This project was developed as part of my final-year capstone. The aim was to design and develop a Warehouse Management System to improve warehouse operations and reduce reliance on manual processes.

## Project Objectives
- Improve inventory and warehouse management.
- Organise warehouse processes through a digital system.
- Apply systems analysis, design, and software development principles.
- Develop teamwork, communication, and problem-solving skills.

## Skills Demonstrated
- Systems analysis and design
- Software development
- Database management
- Requirements analysis
- Teamwork and collaboration

## Project Context
This project provided practical experience in analysing business processes and developing a software solution to address operational challenges.
